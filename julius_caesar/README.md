# Julius Caesar: The Road to the Rubicon (TikTok, 3:03)

Vertical 1080x1920 / 30 fps pixel-art history video. Covers Caesar's rise
(100-63 BC), the First Triumvirate (60 BC), Gaul and Alesia, the alliance's
collapse, the Rubicon (49 BC), the civil war against Pompey (Italy, Spain,
Dyrrhachium, Pharsalus, Pompey's death in Egypt) and an epilogue up to the Ides
of March (44 BC).

Final render: `output/julius_caesar_rubicon_tiktok.mp4`

## How it is made

Everything is generated by code. No stock footage or image assets are used.

| File | Role |
|------|------|
| `script.py` | Narration, one entry per scene, with IPA overrides for Latin names |
| `tts.py` | Narration via [Kokoro](https://github.com/thewh1teagle/kokoro-onnx) (voice `am_michael`) |
| `pixel.py` | Palette, pixel fonts, easing, drawing primitives |
| `sprites.py` | Procedural figures, horses, ships, buildings, icons, coin-style portraits |
| `geo.py` | Hand-traced Mediterranean coastlines and a pixel map renderer |
| `scenes.py` | 22 scene animations; visual beats keyed to narration words |
| `captions.py` | Word timing (pause-aligned) and karaoke caption layout |
| `audio.py` | Procedural chiptune score, synthesized SFX, ducking |
| `render.py` | HUD/timeline, captions, transitions, parallel render, mux |

Frames are drawn at 270x480 and scaled x4 with nearest-neighbour sampling.

## Rebuild

```bash
pip install kokoro-onnx soundfile numpy pillow   # ffmpeg must be on PATH
# model files from the kokoro-onnx "model-files-v1.0" release:
#   kokoro-v1.0.onnx, voices-v1.0.bin  ->  MODEL_DIR
python tts.py MODEL_DIR /tmp/jc_audio
python render.py /tmp/jc_audio output/julius_caesar_rubicon_tiktok.mp4
# stills for review:  python render.py /tmp/jc_audio sheet.png --still rubicon:8 pharsalus:6
```

## Historical notes

Main sources: Suetonius (*Divus Julius*), Plutarch (*Caesar*, *Pompey*),
Caesar (*Bellum Gallicum*, *Bellum Civile*) and Cassius Dio.

- **Figures given by ancient writers:** the army sizes at Pharsalus (22,000
  against about 45,000; 1,000 cavalry against 7,000) are Caesar's own numbers.
  The Alesia wall lengths (11 and 14 Roman miles, about 16 and 21 km) also come
  from Caesar, as does the figure of about 80,000 defenders.
- **"Alea iacta est"** is Suetonius's Latin. Plutarch says Caesar quoted it in
  Greek. The 10 January date is the traditional one, on the pre-Julian
  calendar.
- **Mark Antony** is shown as one of the tribunes who vetoed and fled. Quintus
  Cassius fled with him.
- **"Et tu, Brute"** comes from Shakespeare, so it is left out. The 23 wounds
  and the statue of Pompey come from Suetonius and Plutarch.
- **Fonts:** Press Start 2P, Silkscreen and VT323, all under the SIL Open Font
  License, in `assets/fonts`.
